How Hash Chain Verification Works

  1. Each access decision creates a cryptographically linked record.
  2. Record N's hash is computed over all its fields plus the previous record's hash.
  3. If any field in any record is changed, its hash changes, breaking all subsequent links.
  4. The verifier replays every record from the genesis (previous_hash="0") and recomputes each hash.
  5. A mismatch at any point proves tampering occurred at that record.
